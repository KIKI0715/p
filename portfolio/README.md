# Emberfall Saga — 플레이하는 개인 페이지

3인칭 액션 게임처럼 돌아다니며 소개·기술·프로젝트·연락 기록을 하나씩 깨우는 한 파일짜리 개인 페이지.

- 실행: `portfolio/index.html`을 브라우저로 열거나 아무 정적 호스팅에 올리면 됩니다 (빌드 없음, three.js r128만 CDN에서 로드).
- 내용 수정: `index.html` 안의 `PROFILE` 객체만 고치면 됩니다.
- 조작: WASD 이동 · 마우스 시점 · 클릭으로 불씨날 던지기/회수 · Space 구르기 · E 조사 · J 일지. 모바일은 왼쪽 드래그 이동, 오른쪽 드래그 시점.
- 게임을 건너뛰고 싶은 방문자를 위해 타이틀에 "게임 없이 바로 보기"가 있습니다.

세계관, 캐릭터, 무기, UI는 모두 자체 제작한 오리지널입니다.
